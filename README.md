# Quant-Python

This repository contains my Python coursework, quantitative finance exercises, trading simulations, and projects as I prepare for quantitative trading roles.

## Goals

- Build strong Python fundamentals for quantitative finance and trading
- Practice probability, statistics, data analysis, and numerical methods
- Develop market and trading simulations
- Build backtests and research workflows
- Complete an employer-ready final project

## Repository Structure

```text
Quant-Python/
├── assignments/
├── projects/
└── final_project/
```

### `assignments/`
Weekly course assignments, exercises, and practice problems.

### `projects/`
Standalone quantitative finance and trading projects developed throughout the course.

### `final_project/`
The capstone project for the course, designed to demonstrate quantitative trading, programming, data analysis, and research skills.

## Topics

This repository will grow to include work in areas such as:

- Python fundamentals
- NumPy and pandas
- Probability and statistics
- Financial data analysis
- Expected value and risk
- Portfolio mathematics
- Options and derivatives
- Backtesting
- Market microstructure
- Trading strategy research
